## 계약 때문에 동일하게 복제하지 않은 부분
- 시안 모집중/선정대기/체험중/설정미완료 캠페인 상태는 목록 API에 직접 제공되지 않습니다. 공개/비공개로 표시합니다. 임의 상태 추정 금지.
- 시안 누적 선정·수락·제출 수치는 현재 신청 응답 상태를 누적으로 추론하면 오해가 생깁니다. 실제 SELECTED/ACTIVE/CONTENT_SUBMITTED 현재건수를 '수락 대기·참여 중·제출 상태'로 명시했습니다. 조회 실패는 —로 표시합니다.
- 캠페인 대표/상세 이미지 저장필드/업로드 endpoint 없음. 상품용 POST /products/:id/thumbnail을 캠페인으로 재사용하지 않습니다. 중립 M 썸네일 유지.
- 방문은 visitGuide 자유텍스트만 제공, 구조화 위치/주소 미지원. 표시채널목록 없음, channelGuide 자유텍스트와 단일 requirement.channelType만 존재. 시안 이미지·위치·표시채널 선택을 저장 기능처럼 추가하지 않습니다.
- 운영자 추천/선정 모드 API 없음. 직접 선정만 유지합니다.
- 참여자 지표 원문/출처/측정일, 타업체 이력, 콘텐츠 전체이력 미제공. 비교에는 현재 업체 신청 메시지/답변/조건스냅샷/현재상태만 사용합니다.
- 승인 동의문 정본/필수정책 미확정. 미리보기에서 법무 승인/신청 가능 여부를 판정하지 않습니다.
- 시안의 배송·방문 기록, 결과요약은 이번 디자인 보완에서 별도 운영 기능으로 확장하지 않았습니다. 기존 주문·배송 관리 링크 유지.
- 미션/추가 단계일정 등 기존 숨은 캠페인 필드 보존 로직 유지. 이번 변경은 입력 계약 확장이 아닙니다.
