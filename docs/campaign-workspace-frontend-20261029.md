# 내 캠페인 작업공간 프론트 연결 — 2026-10-29

## 사용 경로

- 사용자: `/mypage/campaigns` → 캠페인 선택 → 일정·미션·연락처·콘텐츠 제출.
- 브랜드: `/seller/campaigns` → 상세 보기 → 공개 담당자 연락처 저장/재조회.
- 브랜드: `/seller/participants` → 신청 상세 → 해당 참여자 제출 콘텐츠 확인.
- 브랜드: `/seller/contents?applicationId=26` → 콘텐츠 검토 → 수정 요청 또는 업체 검토 완료.

## 연결과 정책

`GET /api/campaigns/applications/mine/workspaces`의 application/campaign/brandContact/content를 함께 사용합니다. 조회 실패를 빈 신청 또는 미제출 상태로 바꾸지 않습니다. 목록 선택은 applicationId 검색 매개변수에 유지됩니다.

기존 CampaignSchedule과 서울 시간·종료 제외 경계 모델을 재사용합니다. 신청·선정·체험·콘텐츠·결과발표 기간을 요약과 월 이동 달력으로 표시합니다. 없는 일정/요청사항/연락처는 생성하지 않습니다. 콘텐츠 마감은 연월일·시각과 “전까지”를 표시합니다.

브랜드 연락처는 서버가 제공한 명시 등록 담당자만 사용합니다. 신청 접수·미선정·취소는 비공개 안내, 선정 이후 null은 미등록 안내입니다. 본인 신청 배송 정보는 별도 영역이며 회원 전화번호를 브랜드 연락처로 자동 입력하지 않습니다. 담당자 저장은 소유 브랜드 전용 GET/PUT `/api/collaborations/campaigns/{id}/contact`입니다.

콘텐츠는 기존 참여 수락/체험 확인 상태를 유지하고 POST `/api/campaign-contents/applications/{id}/links`로 제출합니다. INSTAGRAM/BLOG/YOUTUBE/CLIP/OTHER, 최대 5개, 중복 URL 차단, Instagram 게시물·릴스 경로를 확인합니다. 외부 링크를 자동 조회하지 않습니다. 사설 주소 등 최종 공개 URL 검증과 인가는 서버가 수행합니다. 최초 제출은 등록된 제출 기간에만 열리고 수정 요청 재제출은 마감 후에도 가능합니다. 버전 0은 보존하고 충돌·불명확한 결과에서는 재조회 전 중복 전송을 막습니다.

최신 제출 시각, 최근 검토 시각·의견, 수정 요청 횟수, 채널별 링크를 표시합니다. 서버에 없는 전체 과거 URL/검토 이력은 만들지 않습니다. 업체 검토 완료와 운영자 최종 승인을 구분합니다.
