- 목록: `GET /api/campaigns/applications/seller`의 `creatorMetrics`, `creatorChannelUrl`, `completedCampaignCount`. 목록 행별 상세 추가 요청은 없습니다.

- 완료 0회는 신규 참여자로 표시하며 누락된 수치는 0으로 바꾸지 않습니다.

- 기존 브랜드 직접 선정/운영자 선정 권한과 중복 제출 방지는 유지합니다. 상세 조회 실패 중에는 선정 작업을 제공하지 않습니다.
